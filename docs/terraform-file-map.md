# Terraform File Map

## Purpose

This document explains every important file in this repository.

Use this when you want to understand which file to edit, which file to leave alone, and where to run Terraform commands.

## Beginner Rule

Most beginners only need to edit these files:

    environments/dev/terraform.tfvars
    environments/dev/main.tf

    environments/staging/terraform.tfvars
    environments/staging/main.tf

    environments/prod/terraform.tfvars
    environments/prod/main.tf

The reusable module files under modules/proxmox-vm should not be edited unless you want to change how all VMs are created.

## Environment Folders

Each environment has its own folder.

    environments/dev
    environments/staging
    environments/prod

Each environment is executed separately.

Do not run Terraform from the repository root.

Run Terraform from one environment folder at a time.

Example:

    cd environments/dev
    terraform init
    terraform validate
    terraform plan
    terraform apply

## Dev Environment Files

Folder:

    environments/dev

This creates:

    dev-cp-01
    dev-worker-01
    dev-worker-02

### environments/dev/versions.tf

Purpose:

    Defines the Terraform version and Proxmox provider version.

Beginner action:

    Do not edit this file unless you are intentionally upgrading Terraform provider versions.

### environments/dev/provider.tf

Purpose:

    Configures the Proxmox Terraform provider.

It uses values from terraform.tfvars.

Beginner action:

    Usually do not edit this file.

### environments/dev/variables.tf

Purpose:

    Defines all input variables required by the dev environment.

Beginner action:

    Usually do not edit this file.

### environments/dev/main.tf

Purpose:

    Defines the dev VM names, VM IDs, roles, IP addresses, CPU, memory, and disk size.

Edit this file if you need to change:

    VM names
    VM IDs
    IP addresses
    gateway
    CPU
    memory
    disk size

Default dev VM values:

    dev-cp-01       192.168.10.11
    dev-worker-01   192.168.10.21
    dev-worker-02   192.168.10.22
    gateway         192.168.10.1

### environments/dev/outputs.tf

Purpose:

    Shows useful output after Terraform creates the VMs.

Examples:

    VM names
    VM IDs
    VM IP addresses
    VM roles

Beginner action:

    Do not edit this file unless you want different Terraform outputs.

### environments/dev/terraform.tfvars.example

Purpose:

    Example variables file.

This file is safe to commit.

Beginner action:

    Copy this file to terraform.tfvars before running Terraform.

Command:

    cp terraform.tfvars.example terraform.tfvars

### environments/dev/terraform.tfvars

Purpose:

    Your real local values.

This file is not committed to GitHub.

You create it yourself by copying terraform.tfvars.example.

Edit this file and replace:

    REPLACE_WITH_YOUR_PROXMOX_IP_OR_DNS
    REPLACE_WITH_YOUR_PROXMOX_API_TOKEN
    REPLACE_WITH_YOUR_PROXMOX_NODE_NAME
    REPLACE_WITH_YOUR_SSH_PUBLIC_KEY

Never commit this file.

## Module Folder

Folder:

    modules/proxmox-vm

This is the reusable Terraform module.

The environment folders call this module.

Beginner action:

    Do not edit this folder unless you want to change how all VMs are created.

## Module Files

### modules/proxmox-vm/versions.tf

Purpose:

    Tells Terraform this module uses the bpg/proxmox provider.

Do not remove this file.

### modules/proxmox-vm/main.tf

Purpose:

    Contains the actual Proxmox VM resources.

This file creates:

    Ubuntu cloud image download
    cloud-init user-data snippet
    Proxmox virtual machine
    VM disk
    VM network device
    static IP configuration

Beginner action:

    Do not edit unless changing VM creation logic.

### modules/proxmox-vm/variables.tf

Purpose:

    Defines inputs that the module requires.

Examples:

    Proxmox node name
    datastore names
    network bridge
    SSH username
    SSH public keys
    VM map

Beginner action:

    Do not edit unless changing module inputs.

### modules/proxmox-vm/outputs.tf

Purpose:

    Returns useful values from the module.

Examples:

    VM names
    VM IDs
    VM IP addresses
    VM roles

Beginner action:

    Do not edit unless changing outputs.

### modules/proxmox-vm/cloud-init/user-data.yaml.tftpl

Purpose:

    Cloud-init template used to configure Ubuntu when the VM boots.

It creates the Linux user, adds SSH keys, installs basic packages, and starts qemu-guest-agent.

Beginner action:

    Usually do not edit this file.

## GitHub Actions Files

Folder:

    .github/workflows

### .github/workflows/terraform-check.yml

Purpose:

    Checks Terraform formatting and validation automatically when files are pushed to GitHub.

It runs:

    terraform fmt -check -recursive
    terraform init -backend=false
    terraform validate

This workflow does not create VMs.

### .github/workflows/markdown-check.yml

Purpose:

    Checks Markdown files.

This workflow does not deploy anything.

## Most Common Beginner Tasks

### I want to change VM IP addresses

Edit:

    environments/dev/main.tf

Change:

    ip_address
    gateway

Example:

    ip_address = "192.168.1.111"
    gateway    = "192.168.1.1"

### I want to change VM CPU

Edit:

    environments/dev/main.tf

Change:

    cpu_cores = 4

### I want to change VM memory

Edit:

    environments/dev/main.tf

Change:

    memory_mb = 8192

### I want to change VM disk size

Edit:

    environments/dev/main.tf

Change:

    disk_gb = 80

### I want to change Proxmox IP or token

Edit:

    environments/dev/terraform.tfvars

Do not edit provider.tf for normal use.

### I want to change Proxmox storage

Edit:

    environments/dev/terraform.tfvars

Change:

    image_datastore_id
    vm_datastore_id
    snippet_datastore_id
    cloud_init_datastore_id

### I want to change Proxmox bridge

Edit:

    environments/dev/terraform.tfvars

Change:

    network_bridge

## Execution Reminder

Run Terraform from the environment folder only.

Correct:

    cd environments/dev
    terraform init
    terraform validate
    terraform plan
    terraform apply

Incorrect:

    cd kp-terraform-infra
    terraform apply

## Summary

For normal use, beginners mostly edit:

    terraform.tfvars
    main.tf

The module folder contains reusable code and should usually be left alone.
